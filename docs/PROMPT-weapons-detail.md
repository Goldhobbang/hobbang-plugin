## 무기 3종 디테일 리모델링 (뇌운 전투도끼, 크리스탈 대검, 크로노 낫)

먼저 루트 AGENT_PROMPT.md, docs/PROGRESS-1.5.2.md, docs/img/1.5.2/weapons_compare.jpg를 보고, 원본 메시(models-3d/weapon_tempest-battleaxe.zip, weapon_crystal-greatsword.zip, weapon_chrono-scythe.zip)와 원본 텍스처를 열어 비교한 뒤 시작해.

### 충돌 방지
- 다른 에이전트가 지금 대장장이와 마그마 단조 망치(1.5.3)를 작업 중이다. 대장장이/망치 관련 파일과 BossPoses.smith는 건드리지 마.
- `git worktree add ../hobbang-plugin-weapons -b feat/weapons-detail`로 작업 폴더를 분리하고 그 안에서만 작업해. main merge/push 금지. 단, main 작업 트리에 미커밋 1.5.2 변경이 있으면 그 상태를 worktree로 복사해 기반으로 쓰고, 복사 커밋은 따로 표시해.
- Paper 서버 실행 금지.

### 공통 방식 (1.5.2 유지)
- 큼직한 큐보이드 판 조합, 16px/블록 손픽셀 텍스처, 랜덤 노이즈 금지, 원본 추출 팔레트만 사용.
- 1.5.2는 도형이 너무 적어 원본 디테일이 빠졌다(원본 각 ~1만 삼각형, 1.5.2는 29~54 큐보이드). 아래 상한 안에서 원본 실루엣과 장식을 최대한 복원.
- MC 요소 회전 제한(단일 축, ±45°, 22.5° 단위) 준수. 큰 곡선은 계단식 큐보이드 배치로.
- display_context(손 3D, GUI/바닥/액자 2D)와 grip 값 유지. 2D 16px 아이콘도 새 모델에 맞게 다시 그림.
- 텍스처는 필요하면 256×256까지. 기존 애니메이션 프레임(번개 점멸 등) 유지.

### 1. 뇌운 전투도끼 (stormcaller): 큐보이드 500개 이하
- 원본 도끼머리 가운데 드래곤(머리, 목, 몸통, 꼬리)을 입체로 복원 (1.5.2에서 빠짐).
- 양쪽 날개: 뼈대(날개 팔+손가락 뼈), 막, 칼날 같은 톱니 가장자리를 층층이. 빗살처럼 평평하게 나열 금지.
- 황금 번개 혈관이 날개와 몸통을 따라 이어지게. 자루의 검정/금 꼬임 장식과 폼멜도 원본처럼.

### 2. 크리스탈 대검 (crystal_greatsword): 큐보이드 300개 이하
- 검신 양옆 결정 톱니가 불규칙하게 돋아나게, 검신 중앙 결정 결/빛 반사는 텍스처로.
- 가드(날개처럼 뻗은 결정), 손잡이 감김, 폼멜 결정을 원본 비율로.

### 3. 크로노 낫 (chrono_dagger): 큐보이드 350개 이하
- 크게 휘어진 낫날 곡선을 계단식 배치로 매끄럽게, 날 안쪽 금속 무늬와 청록 룬.
- 날 뿌리 시계 장식(시계판, 톱니바퀴)을 입체로, 긴 자루 마디 장식과 끝 장식 복원.
