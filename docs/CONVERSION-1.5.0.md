# 1.5.0 모델 변환 — 혼합(복셀 + 기울인 직육면체) 방식

범위: AGENT_PROMPT §1(모델 변환)과 §5(알려진 버그). 관절 세분화(§2)·움직임·패턴은 아직 안 했습니다.
서버·클라이언트는 실행하지 않았습니다. 아래 이미지는 오프라인 렌더(`obj2mc/preview.py`)입니다.

## 방식

- 파트별 `mode`: `voxel`(기존) / `obb`(전부 기울인 박스) / `mixed`(`obb_regions` 안만 박스, 나머지 복셀). config 한 줄로 바꿉니다.
- 박스 피팅(`obj2mc/obb.py`): 파트 voxel을 더 촘촘한 격자(`obb_resolution`)로 다시 뽑고, 연결 덩어리마다
  축·각도 후보(x/y/z 한 축, 0/±22.5/±45°) 중 부피가 가장 작은 박스를 맞춥니다.
  채움률이 `obb_fill`보다 낮으면 가장 긴 축으로 잘라(가장 큰 틈, 없으면 부피 합이 최소인 위치) 재귀로 다시 맞춥니다.
- 마인크래프트 element 회전 제약(단일 축, ±45°, 22.5° 단위)을 지킵니다. 그보다 큰 기울기는 박스를 잘게 나눠 근사하고, 파츠 분리는 하지 않았습니다.
- 텍스처는 박스 면마다 원본 UV에서 레이캐스트로 샘플링합니다(면 평균색 아님). 다른 박스/복셀에 가려진 면은 버립니다.
- 모델 단위(`item_display_scale`)는 기존 값에 고정(`units_per_block`)해서 Java 오프셋·무기 손 변환이 그대로 맞습니다.
- 복셀 파트는 기존과 바이트 단위로 같은 결과입니다(회귀 확인함).

config 키: 전역 `obb_resolution`, `obb_fill`, `obb_min_dim`(박스 최소 길이, 격자 칸 수), `obb_texels_per_block`, `units_per_block`.
파트 키: `mode`, `obb_regions`(영역은 기존 `regions`와 같은 형식, layout 단위), `obb`: {`fill`,`min_dim`,`min_pts`,`max_depth`,`texels_per_block`}.

## 솔직한 평가

- 센티넬 칼날, 낫날·자루, 도끼 날개는 기울인 박스가 곡선·사선을 훨씬 매끈하게 잡습니다. 망치·대검은 개수가 크게 줄고 윤곽도 유지됩니다.
- 대장장이 다리, 콜로서스 다리·몸통 하부는 박스가 다소 납작하고 두꺼워 보입니다(발이 슬래브처럼). 돌 벽돌 질감이 부드러워진 곳도 있습니다.
  인게임에서 어색하면 해당 파트 `mode`를 `voxel`로 되돌리거나 `obb.fill`을 올리면 됩니다(재변환 약 30초).
- 대검은 끝이 뾰족하게 좁아지는 부분이 단순화돼 있습니다(`obb_min_dim`을 낮추면 개선, 박스 증가).
- 센티넬 박스 수가 적게 줄어든 것은 몸통·링·시계가 복셀 디테일이라 일부러 남겼기 때문입니다.

## 인게임에서 꼭 확인할 것 (제가 못 본 것)

1. **element 회전 방향**: 박스 기울기의 부호는 클라이언트의 `FaceBakery`가 표준 회전행렬을 쓴다는 가정으로 만들었고,
   오프라인 렌더도 같은 가정입니다. 인게임에서 기울어진 판(낫날, 센티넬 칼날, 도끼 날개)이 원본과 같은 방향인지 확인해 주세요.
   반대로 기울어 있다면 `obj2mc.py`의 `angm = ... if ax == 1 else -...` 한 줄 부호만 바꾸면 됩니다.
2. 무기 손 grip: 모델 단위와 pivot을 기존 값에 고정했으므로 display 값은 그대로입니다. 그래도 4종 모두 1인칭/3인칭에서 방향·위치를 봐 주세요.
3. 박스 면이 서로 파고드는 곳의 z-fighting(같은 파트 안에서 겹친 면). 가려진 면은 대부분 버렸지만 완전하지 않을 수 있습니다.

## 알려진 버그 수정 (§5)

- 대장장이 죽음: `SmithBoss.serverTick`에 `dying` 분기가 없어 `tickDeath`/`finishDeath`가 한 번도 돌지 않았음 → 분기 추가. (무릎 꿇기가 안 보이던 원인으로 확정)
- 나머지 3종 죽음 지연: `finishDeath`가 `dead=true`를 먼저 세운 뒤 보상·투기장 복구에서 예외가 나면 파츠 discard가 영영 실행되지 않는 구조였음 → 단계별로 격리, `tickDeath`의 연출 예외도 격리. 처치 방송의 "누군가"는 마지막 타격자(`lastHitter`)로 보강. (원인 후보 중 정적 분석으로 확인 가능한 것만 고쳤고, 실제로 지연되던 정확한 사례는 재현 못 함)
- 와이번 급강하/착지: `setVelocity` Y가 먹지 않는 좀벌레 대신, Y 이동은 승객(파츠)을 유지하는 텔레포트(`drive()`)로, XZ는 기존 속도로. 블록 관통은 아래로 갈 때만 검사. 사망 낙하도 같은 경로.
- 첫 대장장이 스파이크: `BossWarmup`이 보스 클래스 초기화와 위더 스켈레톤+장비+발광 디스플레이 승객 경로까지 한 번 미리 밟음. **측정은 못 했으므로 효과 미확인.**

## 재현

```
cd obj2mc   (venv: numpy pillow scipy trimesh rtree shapely embreex)
python obj2mc.py configs/abyssal_smith.json --preview        # 팩/매니페스트/비교 이미지(../work/previews)
python ../weapons/rebuild_hands.py                           # 무기 hand 모델 + 애니메이션 텍스처 갱신
python make_java_rig.py && python validate_pack.py
```

메시는 `models-3d/*.zip`을 `work/models/<zip 이름>/`에 풀어 두면 config의 `/workspace/...` 경로 대신 파일명으로 찾습니다.
이전 config는 `*.v144-voxel.json` / `tempest_wyvern.v144-final.json`로 보관했습니다.
