# HobbangEnhance 1.5.0 인게임 테스트 계획

Paper 1.21.11 테스트 서버와 Minecraft 1.21.11 클라이언트에서 진행합니다. 테스트 담당자는 `dist/`의 1.5.0 jar와 팩 zip을 같은 버전으로 준비하고 `SHA1SUMS.txt`와 대조합니다. 평지에 보스 한 마리씩 소환하고, 공격 패턴은 생존 모드 플레이어로 유도합니다. 보스 근접 정면·측면과 발밑이 함께 보이는 각도에서 기록합니다.

## 보스별 확인 장면

| 소환 명령 | 장면 | 기대 동작과 확인 포인트 |
|---|---|---|
| `/hobbang boss abyssal_smith` | 조립 → 추적·보행 → 망치 내려찍기 → 화염구·충격파 → 페이즈 2·3 | 골반과 가슴이 체중 이동을 따라 회전하고, 무릎·팔꿈치가 관절 방향에 맞게 굽힙니다. 오른손이 망치를 쥔 채 머리 위로 들고, 붉은 원 중앙 방향으로 망치 머리가 떨어진 뒤 회복합니다. 타격 프레임과 소리·폭발의 시점, 손잡이 분리나 바닥 관통 여부를 확인합니다. |
| `/hobbang boss prism_colossus` | 조립 → 보행 → 양 주먹 내려찍기 → 수정 가시·빔·비 → 페이즈 2·3 | 걸을 때 다리가 번갈아 무게를 받고, 팔·주먹과 수정이 미세하게 떨립니다. 내려찍기 전 양 팔을 들고, 빔·수정 가시·비는 각각 시전 자세에서 발동한 뒤 회복합니다. 팔·주먹 연결부와 빔이 머리 부근에서 시작하는지 확인합니다. |
| `/hobbang boss chrono_sentinel` | 조립 → 부유·시선 → 칼날 휘두르기 → 시간 정지 → 시간 역행 성공·저지 | 링·시계가 함께 움직이고 팔을 따라 칼날이 늦게 움직입니다. 시간 정지 카운트다운 끝에 기어가 멈췄다가 다시 돌고, 시간 역행 시 반대로 돕니다. 역행을 저지하면 과부하 자세와 라벨을 확인합니다. |
| `/hobbang boss tempest_wyvern` | 조립 → 선회 → 급강하 예고·급강하 → 착지·휴식 → 재이륙 → 페이즈 2·3 | 몸통이 날갯짓에 맞춰 오르내리고 선회 방향으로 기울어집니다. 날개가 어깨·전완·손가락 순으로 움직이고 좌우가 대응합니다. 급강하 시 히트박스 Y가 내려가고, 착지 시 발과 정강이가 충격을 받아 접힙니다. 3초 휴식에서 네 발 접지, 날개가 몸 옆으로 접히는 방향, 목·척추·꼬리 연결부, 날개막 틈과 바닥 관통을 확인합니다. 재이륙 후 몸을 펴는 동작도 봅니다. |

대장장이는 체력 66%·33%, 나머지는 60%·30%에서 페이즈가 전환됩니다. 구간별로 천천히 체력을 줄이며 전환 자세와 기존 대사·색·이펙트를 확인합니다. 공격이 겹치면 예고 → 타격 → 회복 사이에 포즈가 튀는지 보고, 예고 원·광선·낙하 지점에 비해 타격 프레임이 앞서거나 밀리는 장면을 기록합니다.

## 폴백 및 정리

1. 테스트 서버의 `plugins/HobbangEnhance/hobbang-enhance.json`에서 `bossModels`를 `off`로 설정하고 `/hobbang reload`를 실행합니다. 네 보스를 새로 소환해 대장장이의 확대 위더 스켈레톤과 나머지 세 보스의 블록 모델이 보이는지 확인합니다. 서버 팩 URL이 비어 있는 테스트 환경에서 `auto` 분기도 확인합니다.
2. 서버 팩 URL이 설정된 테스트 환경에서 `auto`로 네 보스의 조립과 전투를 다시 확인합니다. `auto`는 서버 팩 URL을 기준으로 모델 모드를 고릅니다. `/hobbang displays`는 활성 이펙트도 포함하므로 조립·공격 이펙트가 가라앉은 시점에 기록합니다.
3. 각 보스에 생존 모드 플레이어가 마지막 타격을 가합니다. 치명타 직전과 애니메이션 종료 후에 `/hobbang displays`를 기록합니다. 대장장이 무릎 꿇기 약 100틱, 콜로서스 파편 약 100틱, 센티넬 정지·퇴장 약 150틱, 와이번 추락·퇴장 약 110틱을 기준으로 봅니다. 이후 보스바·히트박스·파츠·공격 이펙트가 정리되고 처치 메시지와 전리품이 한 번 처리되는지 확인합니다. 자연 정리가 끝났는지 기록한 뒤 필요할 때 `/hobbang displays clean`을 사용합니다.

## 성능 및 첫 소환

1. 1.4.4와 1.5.0을 같은 월드, 시야 거리, 인원, 위치에서 비교합니다. 서버 시작 직후와 워밍업 완료 로그 직후에 `/mspt`를 기록합니다.
2. 워밍업 후 첫 대장장이 소환 직전·직후에 `/mspt`를 기록합니다. 다음 소환과 구분하고 재시작해서 첫 소환을 반복합니다. 이전 첫 소환에서 관찰한 약 104ms 스파이크가 재현되는지, 워밍업 중이나 소환 후 50ms를 넘는 최대 틱이 있는지 확인합니다.
3. 보스별 유휴·조립·추적·대표 공격·사망 구간의 `/mspt` 평균/최대와 `/hobbang displays`를 기록합니다. 와이번은 선회·급강하·착지를 각각 기록합니다. 패킷 캡처가 가능하면 같은 관찰자 기준으로 변환 메타데이터 패킷을 3틱 구간별로 집계합니다.
4. 팩 1.5.0에서 망치·대검·낫·전투도끼를 1인칭과 3인칭으로 들고 그립·방향·크기를 비교합니다. 클라이언트 로그에서 모델 로드 오류와 아이템 아틀라스 크기를 확인합니다.

기록 항목은 버전, 보스, 모드, 페이즈, 동작, FPS, MSPT 평균·최대, 디스플레이 수, 영상 또는 로그 시각입니다.
