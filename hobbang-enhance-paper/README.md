# 홉방 강화 — Paper 1.21.11 플러그인 (v1.4.3)

Fabric 모드 **홉방 강화 1.5.1**을 Paper 플러그인으로 옮긴 버전입니다.
**바닐라 클라이언트로 그대로 접속**할 수 있습니다. 모드, 리소스팩, 데이터팩을 따로 설치할 필요가 없습니다.

## 설치
1. `hobbang-enhance-paper-1.4.3.jar` 파일을 (이전 버전 jar는 지우고) 서버의 `plugins/` 폴더에 넣습니다.
2. **Paper 1.21.11** 서버를 다시 시작합니다(Java 21).
3. 처음 시작할 때 콘솔에 아래 두 줄이 나오면 정상입니다.
   - `Found new data pack HobbangEnhance/provided, loading it automatically`
   - `홉방 인첸트 20종 로드됨`
   - 인첸트와 발전과제가 담긴 데이터팩은 jar 안에 들어 있어서 자동으로 등록됩니다. 별도 데이터팩은 필요 없습니다.
4. 설정 파일은 `plugins/HobbangEnhance/hobbang-enhance.json`에 있습니다. 확률표는 Fabric 판과 같고, 바꾼 뒤 `/hobbang reload`로 다시 읽습니다.
5. 관리자 권한은 `hobbang.admin`이며, 기본값으로 OP에게 주어집니다.

## 기능 (Fabric 1.5.1 기준)

### 강화
- +1부터 +15까지 강화할 수 있습니다. 확률, 재료, 경험치, 장인의 기운은 Fabric 판과 같습니다.
- 주문서: 파괴 방지, 축복, 프리즘, 불멸, 역행 모래시계.
- 행운의 부적을 쓸 수 있습니다.
- +10 이상 강화 시 서버 전체에 공지합니다.

#### 강화 단계 효과 (v1.2.0 개편)
- 무기 공격력 보너스 **하향**: 단계당 +0.3(1~5) / +0.5(6~10) / +0.7(11~15) → +5 = +1.5, +10 = +4, +15 = **+7.5** (이전 +15). +10/+15 공격 속도 +5%/+10%는 그대로.
- 방어구 방어력(+0.3/단계, 11~ +0.6)과 방어 강도(+6~ 0.25/단계), +15 밀려남 저항 +0.1은 그대로. **최대 체력은 흉갑에만** 붙도록 바뀜(이전: 모든 방어구 +10에 +2, +15에 +4).
- 도구 채굴 효율 +1.5/단계는 그대로.
- **+5 / +10 / +15 마일스톤** (장비 설명에 ◆ 달성 / ◇ 미달성으로 표시, 강화 창 확률 정보에 "성공 시 +N: …" / "다음 마일스톤" 표시):

| 장비 | +5 | +10 | +15 |
|---|---|---|---|
| 흉갑 | 최대 체력 +2 | +6 | +10 |
| 투구 | 산소 보너스 +1 | +3 | +9 · 물속 채굴 속도 정상(친수성과 같음) |
| 각반 | 이동 속도 +3% | +6% | +10% |
| 신발 | 안전 낙하 +1칸 · 낙하 피해 −10% | +2칸 · −20% | +4칸 · −35% |
| 검·창 | 휩쓸기 피해 +25% · 출혈 20%(3초간 1씩 3번) | + 관통 15%: 준 피해의 25%를 방어 무시 피해로 한 번 더 | + 장인의 일격: 풀차지 공격 때 반경 3칸 다른 적에게 35% (플레이어·길들인 동물 제외, 3초 쿨다운) |
| 곡괭이·도끼·삽·괭이 | 내구도 보존 10% | 25% | 40% · 블록 파괴 속도 +10% |
| 철퇴 | 들고 있을 때 안전 낙하 +3칸 | + 낙하 피해 −50% | + 낙하 피해 없음 |
| 삼지창 | 들고 있을 때 수영 속도 +33% | +66% · 산소 보너스 +2 | +100% · 산소 +2 · 물속 채굴 정상 |
| 활 · 쇠뇌 | 화살 보존 20% (쏜 화살은 주울 수 없고 1개 돌려받음 → 복사 없음, 무한 화살 제외) | 35% | 50% |
| 방패 | 밀려남 저항 +10% | +20% · 막을 때 발사체 반사 15% | +30% · 반사 30% |
| 보스 무기 | 단계마다 스킬 피해 ×(1+0.04×단계), 범위 +0.1칸/단계, 재사용 −2%/단계 (+15 = ×1.6, +1.5칸, −30%) | 망치 여진 1회 · 전투도끼 낙뢰 연쇄 1 · 낫 정지 시 피해 4 | 망치 여진 2회+구속 · 전투도끼 연쇄 2 · 수정 대검 가시 +1개/5단계, 낫 정지 시간 +0.2초/단계 |

- 활·쇠뇌·방패도 이제 강화할 수 있습니다.
- 속성은 강화·하락·파괴 방지 때마다 처음부터 다시 계산합니다(고정 키 `hobbang:enhance_*`, 중복 없음). **이전 버전에서 강화한 장비는 접속하거나 상자를 열 때 새 표로 자동 재계산**됩니다(`hobbang:stat_ver`=2).
- 특수 효과는 틱 작업 없이 공격·발사·내구도 이벤트에서만 계산합니다.

### 강화대
- 강화석 3개 / 모루 / 흑요석 3개로 조합한 "강화대"(대장장이 작업대 모양)를 설치해서 씁니다.
- **v1.2.0: 우클릭하면 강화 창(상자형 GUI)이 열립니다.** 장비 들고 좌클릭하면 채팅에 확률을 미리 보여 줍니다. 웅크린 채 블록을 들고 우클릭하면 그대로 설치됩니다.
- 폭발, 피스톤, 화염으로부터 보호됩니다.
- 예전 방식(손에 든 장비를 우클릭으로 바로 강화)은 설정 `legacyRightClick: true`로 되돌릴 수 있습니다(기본 false).

#### 강화 창 (6줄 54칸)
| 칸 | 내용 |
|---|---|
| 4 | 안내 (대장장이 작업대 아이콘) |
| 11 | **장비 칸** (강화 가능한 장비만, 1개) — 10번 칸은 "장비 칸 ▶" 표시 |
| 13 | **확률 정보** (인첸트 책 / 장인의 기운 100%면 네더의 별) |
| 15 | 재료 미리보기 (강화석/빛나는 강화석, 개수 = 필요량, 보유 ✔/✘) |
| 16 | 경험치 미리보기 (경험치 병, 개수 = 레벨) |
| 22 | **강화 버튼** (모루 / 못 할 때는 방벽 + 이유) |
| 37~42 | **보조 칸**: 행운의 부적 · 프리즘 주문서 · 축복 주문서 · 파괴 방지 주문서 · 불멸 주문서 · 역행 모래시계 (각 칸에 맞는 것만, 위 28~33은 색 유리 이름표) |
| 49 | 닫기 |

확률 정보(13번)는 **절대 확률 네 가지가 합쳐 100%**가 되도록 보여 주고, 장비·보조 칸이 바뀔 때마다 즉시 갱신됩니다.
- `✦ 성공` = 기본 성공률 + 강화 친화(+3%p/Lv) + 부적(+10%p) + 프리즘(+20%p) (장인의 기운 100%면 100%)
- `✖ 실패(유지)` / `▼ 하락` / `☠ 파괴` = 실패했을 때의 조건부 확률 × (100% − 성공) — 깨짐의 저주(+5%p 파괴) 포함, +0단계는 하락 없음
- 보조 칸에 축복·파괴 방지·불멸·역행이 있으면 "주문서 적용 시 실제 결과" 줄이 추가됩니다(예: 파괴 → 하락, 하락 → 유지).
- 아래에 계산 근거(기본 성공률, 보정치, 실패 시 조건부 하락/파괴)가 함께 나옵니다.
- 버튼은 0.5초 쿨다운. 쓰인 보조 아이템만 칸에서 줄어듭니다. 재료와 경험치는 가방에서 씁니다.

복사 방지: 쉬프트 클릭은 맞는 칸으로만, 숫자키·더블클릭·드래그·표시 아이템 집기는 모두 막힘. 창을 닫거나 접속을 끊거나 서버가 꺼지거나 강화대가 부서지면(명령어로 지워져도 0.5초 안에) 넣은 아이템은 가방으로 돌아오고, 가방이 차 있으면 발밑에 떨어집니다. 죽으면 드롭에 포함. 두 사람이 같은 강화대를 써도 창은 각자 따로입니다. 깔때기 등은 창에 접근할 수 없습니다.

### 시련의 장소 · 소환 (v1.4.0)
보스는 이제 **정해진 장소에서만** 부를 수 있습니다. 구조물은 모두 바닐라 블록이고, 내장 데이터팩 worldgen 이라 `/locate structure hobbang:<이름>` 이 됩니다.
**새로 생성되는 청크에만** 나타납니다(기존 맵의 이미 탐험한 곳에는 생기지 않음 → 멀리 가거나 관리자가 `/hobbang structure place`).

| 보스 | 구조물 (`/locate`) | 크기 (가로×높이×세로) | 생성 위치 | 간격 (spacing/sep, 청크) | 소환 |
|---|---|---|---|---|---|
| 심연의 대장장이 | 심연의 대장간 `hobbang:abyssal_forge` | 61×30×61 (내부 37×37, 벽 14칸 + 부벽·성문탑·용암 수로·대장간 마당) | 네더 현무암 삼각주, y≈33 | 24/8 | 대장간 중앙 **용광로 제단**을 심연의 핵을 들고 우클릭 |
| 프리즘 콜로서스 | 프리즘 정동 `hobbang:prism_grotto` | 47×27×47 (천연 동굴형 지오드: 종유석·이끼·발광 이끼·뿌리) | 오버월드 무성한 동굴 지하 (y −24~16) | 24/8 | 중앙 **신호기 제단** + 프리즘 핵 |
| 크로노 센티넬 | 크로노 신전 `hobbang:chrono_temple` | 57×27×57 (원형 시계 광장 + 구리 톱니 아치·외곽 열주·바닥 톱니) | 오버월드 지표 (평원·초원·사바나·사막·눈 평원·벚나무 숲·숲·자작나무 숲·타이가) | 32/10 | 중앙 **마법부여대 제단** + 시간의 핵 |
| 폭풍의 와이번 | (플레이어가 직접 쌓는 폭풍 제단) | 투기장 반지름 ~15, 높이 +9~+11 | 오버월드 어디든, **천둥번개 칠 때만** | — | 피뢰침을 폭풍의 핵을 들고 우클릭 |

- 제단 블록은 구조물에 PDC(`hobbang:altar`)로 표시돼 있어 일반 용광로/신호기/마법부여대와 구별됩니다. 제단 창은 열리지 않고, 핵이 없으면 안내, 다른 핵이면 "이 제단은 ○○의 것" 안내.
- 기존 5초 의식 → 보스는 투기장 안 정해진 자리에 나옵니다. 근처 64칸에 보스가 있으면 거절.
- **간단한 꼼수 방지**: 보스가 살아 있는 동안 투기장 안 블록 설치·파괴·양동이·피스톤·폭발·엔더맨 등 블록 변경 차단, 제단은 항상 파괴 불가(크리에이티브 + 웅크리기만 예외).
  보스가 투기장 밖으로 끌려 나가면 2초마다 확인해 안으로 되돌립니다.
- **폭풍 제단** (가이드북 5장 '폭풍 제단', `/hobbang storm`, 소환대 → 폭풍의 와이번 칸에서도 볼 수 있음):
  ```
  위에서 본 모습 (5×5, 모두 같은 높이)
    W · · · W     W = 조약돌 심층암 담장 2단 (네 모서리)
    · · X · ·     X = 깎인 구리 ×4 (산화·밀랍 무관)
    · X C X ·     C = 구리 블록 (산화·밀랍 무관) + 그 위에 피뢰침 (구리 피뢰침도 됨)
    · · X · ·
    W · · · W
  재료: 구리 블록 1, 깎인 구리 4, 피뢰침 1, 조약돌 심층암 담장 8
  ```
  천둥번개가 칠 때 폭풍의 핵을 들고 피뢰침을 우클릭 → 제단이 변신(구리 전구 점등, 산화된 깎인 구리, 담장 위 엔드 막대)하고
  번개·파티클과 함께 공중 투기장(원판 반지름 6.5 + 아랫면 원뿔, 위성 발판 5개, 나선 계단 9칸)이 한 틱에 5블록씩 쌓입니다(약 3초) → 와이번 등장.
  **공기·교체 가능한 블록(풀, 꽃, 눈 등)에만** 놓고, 계획 칸의 15% 넘게 막혀 있으면 거절합니다.
  와이번이 죽거나 60초 이상 사라지면 투기장이 거꾸로 무너지며(틱당 8블록) **원래 블록으로 복구**되고, 제단도 처음 모습으로 돌아갑니다.
  진행 중인 투기장은 `plugins/HobbangEnhance/arenas.json` 에 저장돼 서버를 껐다 켜도 이어서 정리됩니다.
- **소환대(스컬크)는 이제 안내·위치 찾기 장치입니다** (소환하지 않음). 우클릭 → 보스 4칸: 클릭하면 가장 가까운 구조물(반경 64청크)의 방향·거리·대략 좌표를 알려 주고 나침반이 그쪽을 가리킵니다(15초 쿨다운, 네더 구조물은 네더 좌표로 안내). 와이번 칸은 폭풍 제단 도면.
  핵을 들고 강화대를 우클릭하면 소환 대신 어디로 가야 하는지 알려 줍니다.

### 보스와 보스 무기
- **v1.3.0 보스 모델 / 크기**
  - 리소스팩 `hobbang-pack.zip` 의 3D 모델(아이템 디스플레이 파츠)로 보스가 보입니다. 설정 `bossModels`:
    `"auto"`(기본) = server.properties 에 `resource-pack` 이 설정돼 있으면 모델, 없으면 예전 블록 모델 /
    `"on"` = 항상 모델(모든 플레이어가 팩을 직접 적용했을 때) / `"off"` = 항상 블록 모델. 바꾸면 `/hobbang reload` 후 1초 안에 다시 만들어집니다.
    팩 없이 `on` 으로 두면 플레이어에게는 종이 아이템이 보이니 주의.
  - 크기(모델 높이 / 히트박스): 대장장이 9.0 / 2.1×7.2 (위더 스켈레톤 ×3, 1.2.0 의 2배) · 콜로서스 7.0 / 3.5×6.75 (철 골렘 ×2.5) ·
    와이번 6.0, 날개폭 ~7.9 / 3.6×2.7 (좀벌레 ×9) · 센티넬 5.0 / 3.36×4.76 (늑대 ×5.6). 이미 소환돼 있던 보스도 붙을 때 새 크기가 됩니다. 블록 모델도 같은 비율로 커집니다.

## 3D 무기 모델 넣는 법 (리소스팩)
- 아이템 정의(`assets/minecraft/items/{mace,diamond_sword,netherite_axe,netherite_hoe}.json`)는 이미
  `custom_model_data` 문자열 `hobbang:<id>` → `display_context` select 구조입니다:
  gui/ground/fixed/on_shelf = `hobbang:item/weapon/<id>_icon`(2D), 나머지(손·머리) = `hobbang:item/weapon/<id>_hand`.
- 3D 모델은 `assets/hobbang/models/item/weapon/<id>_hand.json` 하나만 바꾸면 됩니다. v1.4.3 기준 망치·전투도끼·수정 대검·크로노 낫(`chrono_dagger`) 모두 손에 들면 3D입니다.
  - 메시(OBJ+텍스처)가 있으면: `obj2mc/configs/weapon_<id>.json` 을 만들고(망치/도끼 설정 복사) → `obj2mc.py configs/weapon_<id>.json --preview`
    → `weapons/make_weapons.py` 의 `MODEL3D` 에 `'<id>': '<id>_display.json'` 추가 → 실행. 손 위치는 `<id>_display.json`(1·3인칭) 조정.
  - 직접 만든 Blockbench 모델이면 `<id>_hand.json` 으로 저장(텍스처는 `assets/hobbang/textures/item/weapon/…`). make_weapons.py 는 사람이 만든 `_hand.json` 을 덮어쓰지 않습니다.
- 순서: `obj2mc.py` (보스·무기 설정들) → `make_java_rig.py` → `weapons/make_weapons.py` → `validate_pack.py` → `make_zip.py`.
